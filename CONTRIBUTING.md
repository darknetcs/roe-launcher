# Contributing

Contributions are welcome: open an issue or a pull request.

* Keep GUI-free logic in `crates/roe-core` and cover it with unit tests (`cargo test -p roe-core`).
* Run `cargo fmt` and `cargo clippy` before submitting.
* Describe what you tested and on which distro / desktop / Proton version.
* By contributing you agree that your code is released under the MIT licence of this project.
  Do not add game files or other people's artwork.
